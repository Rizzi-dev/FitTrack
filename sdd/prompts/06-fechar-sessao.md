# Fechar sessão

```
Feche a sessão:
1. Crie sdd/logs/<AAAA-MM-DD>-<assunto>.md com o template (feito, decidido, verificação, pendente).
2. Atualize sdd/memory/estado-atual.md.
3. Se aprendemos algo não óbvio, adicione em sdd/memory/armadilhas.md ou convencoes.md.
4. Se uma decisão relevante foi tomada e não tem ADR, proponha um.
5. Se mexemos também no back, lembre de registrar o log no fittrack-api.
```
