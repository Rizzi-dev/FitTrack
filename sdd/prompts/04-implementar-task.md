# Implementar task

```
Implemente a <TASK-xxx>.

Antes: leia a task, a spec de origem, sdd/memory/convencoes.md e sdd/memory/armadilhas.md.
Durante:
- siga só o escopo da task; se achar algo fora do escopo, anote como sugestão de task nova;
- se a spec estiver ambígua ou errada, pare e me pergunte (não "corrija" a spec sozinho).
Depois:
- rode `npx tsc --noEmit` (e `npm test` se houver testes) e mostre o resultado;
- marque os passos e o status da task; atualize o índice;
- diga quais CAs foram verificados e como.
```
