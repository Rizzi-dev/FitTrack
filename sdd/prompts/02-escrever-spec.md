# Escrever spec

```
Escreva a spec para <RF-xx[, RF-yy]> usando sdd/specs/_template.md.

- Leia os requisitos, as specs relacionadas e o contrato (fittrack-api: sdd/specs/SPEC-000-contrato-api.md).
- Descreva todos os estados: carregando, vazio, erro, sucesso.
- Critérios de aceite no formato Dado/Quando/Então, cada um verificável manualmente ou por teste.
- Se precisar de endpoint ou campo que não existe no contrato, NÃO invente: liste em
  "Perguntas em aberto" e sugira usar o prompt 07-mudanca-de-contrato.
Status inicial: Rascunho. Atualize o índice em sdd/specs/README.md.
```
