# Memória

Fatos curtos e duráveis que alguém (humano ou agente) precisa saber e que **não estão óbvios no
código**. Diferente do log (cronológico), a memória é organizada por assunto e sempre atual:
quando um fato deixa de valer, edite ou apague.

- [estado-atual.md](estado-atual.md): onde o projeto está agora (atualize ao fim de cada sessão)
- [convencoes.md](convencoes.md): padrões de código adotados
- [armadilhas.md](armadilhas.md): problemas que já aconteceram e como evitar
